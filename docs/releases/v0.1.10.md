## Highlights

- Added Hex and text search to the bitstream hex view.
- Added decoded-video-wide bitstream search with direct result navigation.
- Deepened H.264 CABAC residual `coeff_abs_level_minus1` boundary tracking.

## Added

- A single search field that interprets input as UTF-8 text and, when valid,
  as a Hex byte sequence.
- Previous/next navigation for packet matches, including automatic page
  changes for large packets.
- Synchronized match highlighting in both the Hex and ASCII columns.
- Video-wide search across decoded access units with stream, media, access-unit,
  byte-offset, and match-length results.
- Direct navigation from a video-wide result back to the matching packet bytes.
- Unit-tested bitstream search helpers for Hex, text, ambiguous, overlapping,
  empty, and result-limited searches.
- CABAC pre-UEG0 target, remaining-prefix-bin, and continuation-state helpers
  propagated through residual and macroblock partial results.
- Recognition of the single-bin zero UEG0 suffix codeword.

## Changed

- Project version is now `0.1.10`.
- CABAC residual ready-input results now expose whether more pre-UEG0 prefix
  parsing is required without changing existing incomplete-result semantics.

## Notes

- Video-wide search covers all access units decoded at the time the search is
  started. While decoding is still in progress, later access units are not yet
  searchable.
- Video-wide results are limited to the first 5000 matches.
- Matches do not span access-unit packet boundaries.
- CABAC coefficient reconstruction remains intentionally incomplete; the new
  fields expose parsing boundaries and preserve current diagnostics.
